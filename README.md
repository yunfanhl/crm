# 云帆智能客户管理系统

一、产品功能

   云帆智能客户管理系统,包含商机情报，销售线索，客户管理，合同管理等功能

三、下载说明：

    1.下载程序运行包，解压后按README.md文件，按部署说明操作即可。
    
    2.部署的过程中如遇到问题，可以先自行排查或加官方微信群进行沟通。
    
    3.运行包下载后可免费试用两周。过了免费期如还需要继续使用，请联系客户经理进行续费。
